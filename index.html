🎯 About Quiz Challenge

Quiz Challenge एक free educational quiz website है जहाँ विद्यार्थी GK, Science, Maths, Cricket और Bihar Board practice questions हल कर सकते हैं।

क्या मिलेगा?

  • MCQ practice और instant answer checking
  • Timer, lives, streak और level system
  • Class 9–10 practice categories
  • Player score और quiz history

Questions और educational content समय के साथ अपडेट किए जा सकते हैं।

🔒 Privacy Policy

Quiz Challenge का यह version profile name, high score, streak और quiz history जैसी जानकारी आपके browser के local storage में रख सकता है ताकि game की सुविधाएँ काम कर सकें।

यह जानकारी इस HTML game से अपने-आप किसी server पर भेजी नहीं जाती। Browser data हटाने पर local game data भी हट सकता है।

यदि भविष्य में analytics, advertisements या online accounts जोड़े जाते हैं, तो उनकी जानकारी इस privacy page में अलग से स्पष्ट की जाएगी।
